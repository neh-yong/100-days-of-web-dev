# AI Fundamentals

## Overview

Artificial Intelligence is not a single technology. It is a hierarchy where each concept builds upon the previous one.

```
Artificial Intelligence (AI)
        │
        ▼
Machine Learning (ML)
        │
        ▼
Deep Learning (DL)
        │
        ▼
Large Language Models (LLMs)
        │
        ▼
Generative AI (GenAI)
        │
        ▼
AI Agents
        │
        ▼
Agentic AI
```

---

# 1. Artificial Intelligence (AI)

Artificial Intelligence (AI) is the broad field of creating machines that can simulate human intelligence, reasoning, learning, and decision-making.

### Examples
- Chess-playing computers
- Self-driving cars
- Virtual assistants (Siri, Alexa)

---

# 2. Machine Learning (ML)

Machine Learning is a subset of AI where machines learn patterns from data instead of being explicitly programmed with every rule.

### Examples
- Netflix movie recommendations
- Spotify music recommendations
- Spam email detection

---

# 3. Deep Learning (DL)

Deep Learning is a specialized branch of Machine Learning that uses artificial neural networks with multiple layers to solve complex problems.

It is especially useful for:
- Image recognition
- Speech recognition
- Natural language processing

### Examples
- Face ID on smartphones
- Object detection in self-driving cars
- Speech-to-text systems

---

# 4. Large Language Models (LLMs)

LLMs are Deep Learning models trained on massive amounts of text data to understand and generate human language.

They are the "brain" behind many modern AI systems.

### Examples
- GPT-4
- Claude
- Gemini
- Llama

---

# 5. Generative AI (GenAI)

Generative AI uses foundation models (such as LLMs) to create new content.

It can generate:
- Text
- Code
- Images
- Audio
- Video

### Characteristics
- Requires human prompts.
- Generates content.
- Cannot perform external actions on its own.

### Examples
- ChatGPT
- Claude
- Midjourney
- DALL·E
- GitHub Copilot

---

# 6. AI Agents

AI Agents go beyond generating content.

They use an LLM as their reasoning engine and can interact with external tools to complete tasks.

Instead of only answering questions, they can take actions.

### Workflow

```
User
   │
   ▼
LLM (Brain)
   │
   ▼
Tools
 ├── Gmail
 ├── Calendar
 ├── GitHub
 ├── Browser
 └── Database
```

### Characteristics

- Can make decisions
- Uses external tools
- Executes end-to-end tasks
- Requires less human intervention

### Examples

#### Coding
- Claude Code
- GitHub Copilot (Agent Mode)
- Devin

#### Productivity
- Glean
- Sierra
- Moveworks

---

# 7. Agentic AI

Agentic AI is the next evolution.

Instead of one AI Agent, multiple specialized agents collaborate under a coordinator agent to accomplish complex goals.

### Workflow

```
                Coordinator Agent
                      │
     ┌────────────────┼────────────────┐
     ▼                ▼                ▼
Research Agent   Coding Agent   Testing Agent
                      │
                      ▼
               Deployment Agent
```

Each agent has its own responsibility while the coordinator manages the overall workflow.

### Characteristics

- Multiple AI agents
- Collaboration
- Planning
- Self-correction
- Re-planning when failures occur
- Handles complex workflows autonomously

### Examples

- CrewAI
- Microsoft AutoGen
- LangGraph
- Relevance AI

---

# AI Agent vs Agentic AI

| AI Agent | Agentic AI |
|----------|------------|
| Single intelligent agent | Multiple collaborating agents |
| Solves one task | Solves complex workflows |
| Uses tools | Uses multiple specialized agents |
| Limited planning | Advanced planning & coordination |
| Minimal collaboration | Full collaboration between agents |

---

# Generative AI vs AI Agent

| Generative AI | AI Agent |
|--------------|----------|
| Generates content | Performs actions |
| Needs prompts for every step | Can complete end-to-end tasks |
| Cannot use tools directly | Uses external tools |
| Passive | Active |

# Key Takeaways

- AI is the umbrella field.
- ML allows systems to learn from data.
- DL powers modern AI with neural networks.
- LLMs understand and generate human language.
- Generative AI creates new content.
- AI Agents can reason, use tools, and complete tasks.
- Agentic AI coordinates multiple agents to solve complex problems autonomously.
