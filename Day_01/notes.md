# Introduction to Vibe Coding

## What is Vibe Coding?

Vibe Coding is the process of building software by describing what you want to an AI instead of manually writing every line of code. The AI generates the code, and you guide it by giving prompts, reviewing the output, and requesting changes.

---

## Vibe Coding Workflow

1. **Setup**
2. **Plan**
3. **Build**
4. **Review**
5. **Deploy**

---

## 1. Setup & Environment

### Recommended Tool
- Claude Code (Beginner-friendly AI coding assistant)

### Connectors
- **GitHub** – Version control and source code management.
- **Hostinger Connector** – Allows AI to deploy applications directly to a Hostinger VPS.

### Productivity Tip
- Enable **Bypass Permission Mode** to avoid confirmation prompts while the AI is working.

---

## 2. Planning

Avoid vague prompts.

A good prompt should include:
- The goal of the project
- The problem it solves
- The target audience

### Best Practice
- Use voice-to-text tools (e.g., Wispr Flow) to explain your idea naturally.
- Ask the AI to:
  - Create a development plan.
  - Ask clarifying questions before writing code.

---

## 3. Build & Review

### Define the Tech Stack Early

Example:
- Next.js
- React
- Tailwind CSS
- Node.js

This helps the AI make better architectural decisions.

### Reviewing

Use browser tools like:
- **Annotate**
- **Select Element**

These allow you to point to specific UI elements and tell the AI exactly what should be changed.

---

## 4. Skills

Skills are reusable Markdown files or plugins that teach the AI specific workflows or best practices.

Examples:
- Front-End Design
- VibeSec (Security)
- Custom project guidelines

They improve the quality and consistency of AI-generated code without requiring repeated prompt engineering.

---

## 5. Deployment

With the Hostinger Connector, deployment can be handled by AI.

The AI can:
- Deploy the application
- Configure the VPS
- Connect the domain
- Enable HTTPS

This automates much of the deployment process.

---

## Key Takeaways

- Vibe Coding focuses on communicating with AI rather than writing every line of code.
- Planning is more important than prompting randomly.
- Clearly defining the tech stack helps the AI produce better code.
- Connectors allow AI to interact with external services like GitHub and Hostinger.
- Skills provide reusable instructions that improve AI output.
- Deployment can be largely automated using AI-integrated hosting platforms.
